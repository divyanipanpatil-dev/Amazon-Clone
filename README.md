# Amazon Clone

A simple Amazon Clone website made using **HTML and CSS**.

## About

This project is a basic e-commerce website inspired by Amazon.\
It is created for learning and practice purposes.

## Features

-   Home page
-   Account page
-   Amazon-style navigation
-   Beauty products
-   Care products
-   Clothes
-   Electronics
-   Fashion
-   Health products
-   Toys
-   Sign-in page
-   Product images and styling

## Technologies Used

-   HTML
-   CSS
-   Images

## How to Run

1.  Download or copy the project folder.
2.  Open the `amazonclone.html` file in a web browser.
3.  Explore the different pages using the navigation links.

## Purpose

This project is made as a **beginner web development project** to
practice HTML and CSS and understand how an e-commerce website is
structured.
